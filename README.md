# SoftGrowTech_Movie_Dataset_Analysis
Project on Movie datatset analysis - analyzing ratings, genres and popularity

Movie Data Analysis Dashboard

Overview
This project performs exploratory data analysis on a movie dataset to uncover patterns related to:

- Movie genres
- Ratings
- Popularity
- Revenue
- Movie production trends

An interactive dashboard was developed using Streamlit to visualize insights dynamically.

Dataset: TMDB 5000 Movie Dataset
The dataset contains information about 4800+ movies including:
- Title
- Genres
- Popularity
- Vote Average
- Vote Count
- Revenue
- Budget
- Runtime
- Release Date

Tools & Technologies
Python  
Pandas  
NumPy  
Matplotlib  
Seaborn  
Streamlit  


Key Analysis
The project explores:
1. Most common movie genres
2. Highest rated genres
3. Popularity vs movie ratings
4. Popularity vs vote count
5. Top revenue generating movies
6. Budget vs revenue relationship
7. Distribution of movie ratings
8. Movie production trends over time
9. Runtime distribution
10. Top rated movies

Interactive Dashboard
The Streamlit dashboard allows users to:
- Filter movies by release year
- Explore genre distribution
- Analyze ratings and popularity
- Examine revenue and budget relationships
- View movie production trends
